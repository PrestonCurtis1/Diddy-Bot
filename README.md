# Install the official Diddy-Bot
We have gotten the bot verified and are currently working on getting message content intents
1. Open the **Discord Desktop App**
2. Open the `App Directory` in **User Settings**
3. Search for `Diddy Bot`
4. Click `Add App`
5. You can choose to `Add to Server` Or `Add to apps`

If you are unable to add Diddy Bot to your server, you will need to create a custom version.
Instructions for Creating a custom version of the bot are below.
___
